
# Object Detection for Home Robots 🤖

An AI-powered object detection project built using Python and YOLOv8.
It identifies objects in images and generates detection reports.

## Features

- AI-based object detection
- Object names and confidence scores
- Bounding box coordinates
- Object counting
- Annotated image output
- JSON detection report
- Basic home-robot obstacle identification

## Technologies Used

- Python
- Ultralytics YOLOv8
- OpenCV
- Pillow
- Matplotlib
- JSON
