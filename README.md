# Object Detection for Home Robots

AI-powered object detection system for home robotics applications.

## Features
- Real-time object detection
- Support for common household objects
- Optimized for robot navigation

## Installation
```bash
pip install -r requirements.txt
```

## Usage
```bash
python main.py
```

- YOLOv8 / Faster R-CNN (specify your model)
